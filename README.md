# BeverageBilling

Beverage Distribution & Billing Management System.

## Features
- **Admin Dashboard**: Analytics, daily sales, monthly breakdown, inventory alerts.
- **Invoicing & Billing**: GST calculation, itemized invoices, invoice numbering, PDF downloads.
- **E-way Bills**: Automatic and manual e-way bill generation with compliance tracking.
- **Inventory Management**: Stock level tracking, stock alerts, purchase order management.
- **Payment & Ledger**: Outstanding payments, customer ledgers, payment mode tracking.
- **WhatsApp Integration**: Share invoice notifications directly with customers.
- **User / Customer Portal**: View past invoices, place orders, view statements.

## Tech Stack
- **Frontend**: React (Vite), Tailwind CSS
- **Backend**: Node.js, Express.js, MongoDB (Mongoose)

## Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- MongoDB

### Backend Setup
```bash
cd backend
npm install
cp .env.example .env # Configure your database connection and secrets
npm run dev
```

### Frontend Setup
```bash
cd frontend
npm install
npm run dev
```
